# Admin console Phase 2

The console manages products, variants, rates, sets, CAD files, trade leads, orders, order photos and the action audit. It has its own staff sign-in and guarded dashboard. The public layout refresh leaves those screens, permissions and actions in place.

| Area | Phase 2 improvement |
| --- | --- |
| Catalog media | Add a review state for public photography, a way to distinguish photos from renders and a preview of planned crops. Confirm images before featuring them on the homepage. |
| Homepage content | Add a staff-managed collection for factory photos and approved project case studies, with fields for captions, publication status and documented client permission. Review the data model before implementation. |
| Trade and orders | Review lead follow-up and order-stage screens with staff. Surface next actions and separate archived records from active work. |
| Accessibility | Check keyboard focus and screen-reader feedback across product forms, overlays, bulk actions and order-stage updates. |
| Release checks | Use a non-production dataset to exercise staff sign-in, draft-to-active publication, quotation and tracking workflows. |
